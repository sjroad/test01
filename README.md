# 산지로드 결산 자동화 대시보드

취합 결산서(xlsx)를 업로드하면 사이트별 수수료 규칙을 적용해 정산가·마진·마진률을 자동 계산하고,
최종 결산서(xlsx)로 다운로드할 수 있는 프로그램입니다. 파이차트 대시보드와 누적 데이터 검색 기능도 포함합니다.

**두 가지 버전이 들어있습니다. 하나만 골라서 쓰시면 됩니다.**

| 버전 | 실행 파일 | 특징 |
|---|---|---|
| 🖥️ 프로그램(데스크톱) 버전 | `실행_프로그램_윈도우.bat` / `실행_프로그램_맥.command` | 브라우저 없이 **진짜 창(윈도우)**으로 뜹니다. "프로그램처럼" 쓰고 싶으면 이걸 추천합니다. |
| 🌐 웹 버전 | `실행_윈도우.bat` / `실행_맥.command` | 브라우저 탭에서 열립니다. 그래프가 좀 더 화려하고(마우스 올리면 수치 표시) 인터넷 브라우저 화면에 익숙하면 이게 편합니다. |

둘 다 같은 계산 로직(processing.py)을 쓰기 때문에 결과는 동일합니다.

## 가장 쉬운 실행 방법 (더블클릭)

1. 이 압축파일을 풀면 폴더 안에 실행 파일들이 있습니다.
2. 위 표에서 원하는 버전의 실행 파일을 더블클릭하세요. (처음이라면 **프로그램(데스크톱) 버전**을 추천합니다)
   - **윈도우**: "Windows의 PC 보호" 같은 파란 경고창이 뜨면 "추가 정보" → "실행"을 누르세요.
   - **맥**: "확인되지 않은 개발자" 경고가 뜨면, 파일을 마우스 오른쪽 클릭 → "열기"를 눌러야 실행됩니다 (한 번만 하면 됩니다).
3. 검은 창(터미널)이 뜨고 자동으로 필요한 프로그램을 설치한 뒤, 프로그램 창(또는 브라우저)이 열립니다.
   - 처음 실행할 때는 설치 때문에 1~2분 정도 걸릴 수 있습니다. 인터넷 연결이 되어 있어야 합니다.
   - 다음부터 실행할 때도 같은 파일을 더블클릭하면 됩니다. (두 번째부터는 설치를 건너뛰어서 훨씬 빠릅니다)
4. **웹 버전**을 실행했는데 브라우저가 자동으로 안 열리면, 검은 창에 `Local URL: http://localhost:8501`처럼 뜨는 주소를 복사해서 브라우저 주소창에 붙여넣으세요. 또 이메일 입력하라는 문구가 나오면 아무것도 입력하지 말고 그냥 Enter만 누르면 됩니다.
5. 다 쓰고 나서 끄려면, 프로그램 창(또는 브라우저 탭)과 검은 창(터미널)을 닫으면 됩니다.

파이썬 자체가 설치되어 있지 않다면 [python.org](https://www.python.org/downloads/) 에서 먼저 설치해주세요.
윈도우에서 설치할 때 **"Add Python to PATH"** 체크박스를 꼭 체크해야 합니다.

## 팀원끼리 공유해서 같이 쓰기 (같은 사무실 네트워크)

지금 만든 프로그램은 기본적으로 "내 컴퓨터에서만" 열립니다. 같은 사무실 와이파이/네트워크에
있는 팀원들과 같이 쓰고 싶다면 아래 방법을 쓰세요. (⚠️ **데스크톱(프로그램) 버전은 공유가 안 되고,
웹 버전만 가능합니다** — 창 하나가 뜨는 방식이라 다른 컴퓨터에서 접근할 수 없어요.)

1. 대표(호스트)가 될 컴퓨터 한 대에서 `실행_팀공유_윈도우.bat` 을 더블클릭합니다.
2. 처음 실행하면 윈도우 방화벽에서 "Windows Defender 방화벽에서 이 앱의 일부 기능을 차단했습니다"
   라는 팝업이 뜰 수 있습니다 → **"액세스 허용"**을 눌러주세요. (사설/개인 네트워크 체크박스도 체크)
3. 호스트 컴퓨터의 IP 주소를 확인합니다: 새 명령 프롬프트를 열고 `ipconfig` 입력 →
   "IPv4 주소" 항목 (예: `192.168.0.12`)을 확인합니다.
4. 팀원들은 자기 컴퓨터 브라우저에서 `http://호스트IP주소:8501` (예: `http://192.168.0.12:8501`)
   을 입력하면 같은 대시보드에 접속할 수 있습니다.
5. **호스트 컴퓨터가 켜져 있고 이 프로그램이 실행 중일 때만** 팀원들이 접속할 수 있습니다.
   호스트가 컴퓨터를 끄거나 창을 닫으면 팀원들 접속도 끊깁니다.
6. 모든 팀원이 같은 서버(같은 데이터)에 접속하는 것이므로, 업로드하거나 저장한 데이터는
   자동으로 다 같이 공유됩니다 — 별도로 파일을 주고받을 필요가 없습니다.

**참고**: 이 방법은 같은 사무실 네트워크(같은 와이파이/공유기) 안에서만 됩니다. 재택근무처럼
외부에서도 접속하게 하려면 회사 서버에 올리거나(클라우드 배포), 포트포워딩/VPN 설정이
추가로 필요한데, 이건 보안 문제도 있어서 별도로 논의가 필요합니다. 필요하시면 말씀해주세요.

## (참고) 터미널로 직접 실행하는 방법

```bash
# 1) (선택) 가상환경 생성
python -m venv venv
source venv/bin/activate   # Windows는 venv\Scripts\activate

# 2) 패키지 설치
pip install -r requirements.txt

# 3-A) 웹 버전 실행
streamlit run app.py

# 3-B) 프로그램(데스크톱) 버전 실행
python app_desktop.py
```

웹 버전은 실행하면 `http://localhost:8501` 이 브라우저에 자동으로 열립니다.
데스크톱 버전은 별도 창이 바로 뜨며 브라우저를 거치지 않습니다.

## 폴더 구조

```
app_project/
├── app.py                     # Streamlit UI (업로드/대시보드/검색/규칙관리)
├── processing.py              # 핵심 계산 로직 (규칙 적용, 집계)
├── requirements.txt
├── README.md
└── data/
    ├── site_rules.json        # 사이트별 수수료율 규칙 (앱에서 편집 가능)
    ├── cashdeal_exceptions.json  # 캐시딜 예외 상품 요율
    ├── fixed_price_table.csv  # 고정 정산단가 상품 (케이딜/꿈꾸는이웃/홈앤쇼핑/LG복지몰/제트언스)
    └── settlement.db          # 누적 데이터 (SQLite, 최초 저장 시 자동 생성)
```

## 사용 방법

1. **결산서 업로드/처리 탭**
   - 결산 일자를 선택하고 취합 결산서(xlsx)를 업로드하면 자동으로 정산가/마진/마진률이 계산됩니다.
   - 규칙이 없는 사이트/상품은 "확인 필요" 목록에 표시됩니다. (아래 "규칙 관리" 참고)
   - "누적 DB에 저장" 버튼을 누르면 같은 날짜 데이터가 있을 경우 덮어쓰고 새로 저장됩니다 (같은 날짜를 다시 올려도 중복되지 않습니다).
   - "최종 결산서 다운로드" 버튼으로 xlsx 파일을 받을 수 있습니다.

2. **대시보드 탭**
   - 누적 DB에 저장된 데이터를 기준으로 사이트별 정산가/마진 파이차트, 상품 Top10 파이차트, 월별 추이 막대그래프를 보여줍니다.
   - 상단에서 특정 날짜(들)만 골라서 볼 수도 있습니다.

3. **검색 탭**
   - 누적 데이터에서 판매사/상품명/주문번호/결산일자로 검색(부분일치)할 수 있습니다.
   - 검색 결과는 CSV로 다운로드할 수 있습니다.

4. **규칙 관리 탭**
   - **사이트별 정산 규칙**: 판매사명에 특정 키워드가 포함되면 적용되는 요율표입니다.
     - `type`이 `percent`이면 정산가 = 결제금액 × rate
     - `type`이 `same_as_payment`이면 정산가 = 결제금액 (rate는 참고용 1.0)
   - **캐시딜 예외 상품**: 캐시딜은 기본 90%지만 특정 상품만 다른 요율이 적용될 때 여기에 등록합니다.
   - **고정 정산단가 상품**: 케이딜/꿈꾸는이웃/홈앤쇼핑/LG복지몰/제트언스는 결제금액이 아니라
     상품별로 정해진 "개당 정산단가"로 정산가를 계산합니다 (정산가 = 정산단가 × 주문수량).
     새로운 상품이 나오면 이 표에 직접 추가해 주세요.
   - 모든 규칙은 편집 후 각 "저장" 버튼을 눌러야 반영됩니다.

## 문제 해결 (자주 발생하는 오류)

- **실행창에 이상한 글자(깨진 문자)와 함께 "내부 또는 외부 명령이 아닙니다"가 여러 줄 뜸** → 이전 버전 실행파일의 한글 인코딩 문제였습니다. 최신 `실행_윈도우.bat`으로 다시 받아서 실행해주세요 (이 문제는 해결되었습니다).
- **"No module named streamlit"** → 패키지 설치(`pip install`)가 제대로 안 된 상태에서 실행된 경우입니다. 최신 실행파일을 사용하면 설치 로그가 화면에 그대로 보이니, 설치 중 오류가 없는지 확인해주세요. 인터넷 연결도 확인해주세요.
- **"파이썬이 설치되어 있지 않습니다" 라고 나옴** → python.org 에서 설치. 윈도우는 설치 시 "Add Python to PATH" 체크 필수.
- **더블클릭해도 창이 바로 사라짐** → 파이썬 설치가 안 됐거나 PATH 등록이 안 된 경우가 많습니다. 위 항목을 확인하세요.
- **실행은 되는데 브라우저가 자동으로 안 열림** → 검은 창에 뜨는 `Local URL: http://localhost:8501` 주소를 복사해서 브라우저 주소창(검색창 아님)에 직접 붙여넣으세요.
- **"이 앱을 열 수 없습니다" (윈도우 보호 경고)** → "추가 정보" 클릭 → "실행" 클릭.
- **"확인되지 않은 개발자" (맥 경고)** → 파일 마우스 오른쪽 클릭 → "열기" (더블클릭 아님, 처음 한 번만).

## 알아두면 좋은 점 (한계)


- **고정 정산단가 사이트(케이딜 등)의 시드 데이터**는 이전에 받은 최종 결산서를 기준으로
  "가장 많이 나온 단가"를 넣어둔 것입니다. 실제로는 같은 상품이라도 시기에 따라 정산단가가
  바뀔 수 있으므로, 담당자가 주기적으로 "고정 정산단가 상품" 표를 확인/수정해 주셔야 정확도가 유지됩니다.
- 매입단가(원가) 자체가 담당자에 의해 수시로 수정되는 경우, 이 프로그램은 취합 파일에 있는
  매입단가를 그대로 사용합니다. 원가 보정이 필요하면 취합 파일 자체를 수정한 뒤 업로드해 주세요.
- 규칙에 없는 새로운 사이트가 나타나면 "확인 필요" 목록에 뜨므로, 규칙 관리 탭에서 새 규칙을
  추가한 뒤 같은 파일을 다시 업로드해서 재처리하면 됩니다.
